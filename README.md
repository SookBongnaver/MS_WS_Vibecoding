# SK네트웍스 바이브코딩 워크숍

**만들고 싶은 것을 말하고, 직접 실행하고, 동료와 논의하며 발전시킵니다.**

이 워크숍은 정해진 코드의 빈칸을 채우는 수업이 아닙니다. 코딩 도우미를 사용할 환경과 시작 방법을 제공하고, **참가자가 자신의 아이디어를 자유롭게 만듭니다.** 웹앱·업무 도구·에이전트 등 결과물의 형태도 직접 정합니다.

Foundry나 SQL을 먼저 만들 필요는 없습니다. “이 내용을 기억하게 해줘”, “여러 사람이 같이 쓰게 해줘”, “AI가 판단해서 처리하게 해줘”처럼 요구사항을 더하면서 **필요한 연결과 서비스를 그때 검토**합니다. 코딩 도우미가 제안하더라도 계정·비용·권한 승인은 사람이 확인합니다.

## 처음이라면 여기부터

| 순서 | 따라 할 일 | 가이드 |
|---|---|---|
| 1 | 준비물 확인, 코딩 도구 하나 선택, 로그인 | [준비하고 시작하기 Step 1~3](docs/00-workshop.md) |
| 2 | 새 작업 폴더를 열고 만들고 싶은 것을 설명 | [첫 제작 요청 Step 4~5](docs/00-workshop.md) |
| 3 | 작은 기능 하나를 만들고 직접 실행 | [실행과 수정 Step 6~7](docs/00-workshop.md) |
| 4 | 필요한 기능을 추가하며 데이터·AI·공유 연결 검토 | [확장 Step 8](docs/00-workshop.md) |
| 5 | 동료가 사용해보고 피드백을 반영 | [논의·개선·공유](docs/03-improve-and-share.md) |

**공통 필수 준비는 PC, 인터넷, 승인된 코딩 도구 하나와 계정, 작업 폴더입니다.** 모든 참가자가 Python·DB·Azure를 미리 설치하거나 생성해야 하는 것은 아닙니다. 선택 도구의 필수 실행 환경만 먼저 준비합니다.

## 이 워크숍에서 얻어갈 것

1. 막연한 아이디어를 사용 대상·입력·동작·결과로 구체화하는 방법.
2. 자연어로 제작을 요청하고 실행하는 방법.
3. 오류나 마음에 들지 않는 결과를 설명해 수정하는 방법.
4. 기능을 조금씩 추가하고, 필요한 기술을 그때 판단하는 방법.
5. 동료 피드백을 반영해 개선한 결과물과 후속 아이디어.

완성 형태·기술 스택·기능은 고정하지 않습니다. 에이전트를 만드는 경우에는 **코딩 도우미 자체에 업무를 시키는 것과 별도로 실행되는 에이전트를 만드는 것을 구분**합니다.

## 아이디어가 필요하면 — SK네트웍스 관련 주제 5개

아래는 공개 사업 사이트·기사에서 착안한 출발점입니다. 그대로 선택하거나 결합·변형해도 됩니다. 실제 내부 시스템이나 회사 정책을 재현하는 과제가 아닙니다.

| 사업 맥락 | 시작 아이디어 | 첫 제작 요청 예시 |
|---|---|---|
| **워커힐: 호텔·식음·행사 경험** | 고객 조건에 맞는 일정 제안 도구 | “예산과 방문 시간을 입력하면 가상 프로그램을 조합해서 보여줘.” |
| **민팃: 중고폰 매입·회수** | 중고폰 판매 방법 비교·상담 도우미 | “가상 기종과 상태를 선택하면 예상 금액과 판매 방법을 비교해줘.” |
| **SK스피드메이트: 차량 관리** | 정비 이력 정리·접수 준비 도구 | “샘플 정비 이력을 보기 쉽게 정리하고 상담 전에 확인할 질문을 만들어줘.” |
| **인크로스: 광고·마케팅** | 캠페인 성과 비교·개선 도우미 | “가상 광고 데이터를 읽고 어떤 채널을 더 살펴봐야 할지 보여줘.” |
| **SK인텔릭스: 해외 사업 확장** | 파트너 후보 비교·미팅 준비 도구 | “가상의 후보 정보를 비교하고 미팅 때 확인할 질문을 정리해줘.” |

**처음부터 DB나 AI가 없어도 첫 화면·계산·업무 흐름부터 만들 수 있습니다.** AI 판단이 필요하면 실행 모델을, 지속 저장·공동 사용이 필요하면 적절한 저장소를 추가합니다. 처음부터 모든 서비스를 연결하지 않습니다.

## 안전하게 만들기

- 고객 정보·사내 문서·실제 계약 대신 가상 자료를 사용합니다.
- API 키·비밀번호·토큰을 대화창, 코드, GitHub에 넣지 않습니다.
- 설치·삭제·외부 발송·리소스 생성 전에는 변경 범위와 비용을 확인합니다.

- 실제 예약·결제·보상·광고 집행은 연결하지 않고 초안·모의 동작으로 만듭니다.

## 제공 상태

시작 가이드·아이디어·선택 예제 코드를 제공합니다. **실제 코딩 도구 UI와 Azure 통합 실행 스크린샷은 아직 없습니다.** 선택 예제의 로컬 계산은 확인했지만 실제 Azure 모델·DB 연동은 리허설 전입니다. 모의 결과를 실제 실행 화면처럼 제시하지 않습니다.
