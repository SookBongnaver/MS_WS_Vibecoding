# SK네트웍스 업무 에이전트 제작 워크숍

**자연어로 만들고, 실제 데이터로 실행하고, 동료와 논의하며 개선합니다.**

개발 문법을 배우는 시간이 아닙니다. 내 업무의 문제를 정의하고, **코딩 도우미에 자연어로 요청해 DB를 조회하고 도구를 사용하는 업무 에이전트**를 만드는 시간입니다. SK네트웍스 및 관련 사업의 공개 자료에서 출발한 5개 시나리오 중 하나를 선택합니다. Codex CLI·GitHub Copilot·Claude Code 중 사용 가능한 도구를 사용합니다.

> **배포 상태: 따라하기 가이드 + 시작 코드·합성 데이터·강사 참고 구현**
>
> 설치부터 모델·DB 연결, 계산 함수 제작, 에이전트 실행과 저장까지 명령어와 확인값을 제공합니다. 로컬 계산 경로와 모의 모델 도구 루프는 확인했습니다. **실제 Azure 모델·DB 통합 실행, 코딩 도우미 제작 화면과 스크린샷은 아직 확인·촬영 전**입니다. 고객 배포 행사 전 운영자 리허설이 필요합니다. 클라우드에 접속하지 않은 결과를 실제 에이전트 실행으로 표시하지 않습니다.

## 이 워크숍에서 얻어갈 것

워크숍을 마치면 다음을 할 수 있습니다.

1. 업무 요청을 **입력·데이터·도구·결과·제한 조건**으로 구체화합니다.
2. 선택한 코딩 도우미에 자연어로 요청해 에이전트의 업무 도구와 지침을 생성·수정합니다.
3. Foundry의 모델과 Azure SQL Database를 연결하는 역할을 이해합니다.
4. 직접 만든 에이전트를 별도로 실행하고, 실제 DB 조회와 도구 호출을 확인합니다.
5. 숫자·근거·예외 상황을 확인하고, 동료의 피드백을 반영해 개선합니다.

**가져갈 결과물:** 선택한 시나리오의 에이전트 코드, DB 연결·조회 도구, 실행 결과물, 개선한 내용과 남은 과제.

코딩 도우미에 업무를 대신 시키는 데서 끝나지 않습니다. **코딩 도우미를 종료해도 별도로 실행할 수 있는 에이전트**가 제작 목표입니다. 공통 연결·도구 루프는 제공하고 참가자는 비어 있는 업무 함수와 지침을 완성합니다. 운영 서비스 배포 완료를 의미하지 않습니다.

## 어떤 에이전트를 만들까요?

| 선택 | 사업과 연결되는 주제 | 만드는 에이전트 | 주로 다룰 문제 |
|---|---|---|---|
| [01 워커힐](docs/scenarios/01-walkerhill.md) | 호텔·식음·행사 경험 | **고객 일정 제안 에이전트** | 예산·시간·취향을 동시에 만족하는 프로그램 조합 |
| [02 민팃](docs/scenarios/02-mintit.md) | 중고폰 매입·보상·회수 | **중고폰 판매 상담 에이전트** | 조건별 예상 보상과 판매 방법 안내 |
| [03 SK스피드메이트](docs/scenarios/03-speedmate.md) | 차량 관리·정비·보증 | **차량 관리 접수 준비 에이전트** | 정비 이력·보증·예약 가능 시간에 따른 상담 준비 |
| [04 인크로스](docs/scenarios/04-incross.md) | 디지털 광고·캠페인 운영 | **캠페인 개선 제안 에이전트** | 성과 계산·채널 비교·후속 분석 제안 |
| [05 SK인텔릭스](docs/scenarios/05-intellix.md) | AI 웰니스 로보틱스·해외 진출 | **해외 파트너 검토 에이전트** | 후보별 적합성·누락 정보·실사 질문 비교 |

각 주제에는 **업무 상황 → DB 구성 → 제작 프롬프트 → 실행 명령·확인값 → 개선 아이디어 → 논의 질문**이 들어 있습니다. 공통 제공 기능은 **조회 도구 2개 + 실행 루프 + 사용자 확인 파일 저장**이며, 참가자는 **계산·비교 함수 1개와 업무 지침**을 만듭니다. 기본 DB는 `workshop.Record`의 JSON 열을 사용해 다섯 데이터 구조를 단순화했습니다.

이 시나리오들은 공개 자료에서 착안한 교육용 제안입니다. 해당 기업의 실제 내부 업무 시스템·정책·가격·운영 성과를 재현하거나 기존 서비스를 공식 구현하는 것이 아닙니다.

## 환경의 역할

```text
제작 단계
참가자 → 선택한 코딩 도우미 → 에이전트 코드 생성·수정

실행 단계
참가자 → PC에서 실행하는 Python 에이전트
                     ├─ Foundry 모델: 요청 해석·도구 선택·답변 구성
                     ├─ Azure SQL: 시나리오별 합성 업무 데이터 조회
                     └─ 로컬 도구: 계산·비교·결과 파일 저장
```

- **Codex CLI·GitHub Copilot·Claude Code**는 개발 도구입니다. 실행용 모델 인증·과금과는 별개입니다.
- **Foundry**는 이번 실습에서 모델을 제공합니다. 생성과 모델 배포부터 안내합니다.
- **Azure SQL Database**는 시나리오별 데이터를 저장합니다. Cosmos DB는 이번 기본 경로에서 사용하지 않습니다.
- **VS Code**는 폴더·파일·터미널을 확인하는 편집기입니다. GitHub Copilot을 선택한 경우 코딩 대화창도 사용합니다.
- 이번 범위에는 Foundry Agent Service 등록, 클라우드 상시 호스팅, 실제 업무 시스템 변경은 포함하지 않습니다.

## Azure 없이 먼저 내용 확인

저장소를 내려받은 뒤 Python 3.13에서 아래 명령을 실행할 수 있습니다. 패키지 설치 없이 합성 자료와 강사 계산 예제를 확인하는 **오프라인 경로이며 AI 에이전트 실행이 아닙니다.**

```powershell
py -3.13 -m workshop check --local
py -3.13 -m workshop example --scenario walkerhill --mode solution
py -3.13 -m unittest discover -s tests -v
```

실제 에이전트는 [환경 준비](docs/01-environment.md) 후 `python -m workshop run`으로 실행합니다. `starter` 모드의 업무 함수는 처음에 미구현 오류를 내도록 되어 있습니다. [첫 제작 가이드](docs/02-first-run.md)에 따라 직접 완성하세요.

## 실습 원칙

- 고객 정보, 사내 문서, 실제 정비 이력·계약·광고 데이터를 입력하지 않습니다. 준비된 합성 데이터만 사용합니다.
- DB 생성·적재 권한과 에이전트 조회 권한을 분리합니다.
- 모델에 임의 SQL 실행권을 주지 않습니다. 미리 정한 매개변수화 조회 도구를 사용합니다.
- 실제 예약·보상 지급·정비 지시·광고 집행·외부 발송은 수행하지 않습니다. 실행안 또는 초안까지만 만듭니다.
- 모델의 답변을 신뢰하기 전에 원본 데이터와 계산 결과를 확인합니다.
