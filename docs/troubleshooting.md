# 오류 진단 및 조치

[Workshop으로 돌아가기](../README.md)

| 상황 | 확인할 것 | 대응 |
|---|---|---|
| 로그인·제작 기능이 안 됨 | 제공 환경 인증, 도구 이용권, 고객 계정·정책, 사용량 한도 | MS 실습 운영 담당에게 전달; 고객 계정·정책 승인은 고객 IT 담당 확인 |
| CLI 명령을 찾지 못함 | 제공 환경·프로젝트 경로, MS 사전 설치 상태 | MS 실습 운영 담당에게 조치 요청; 참가자 임의 설치 금지 |
| 파일이 바뀌지 않음 | 작업 폴더, Agent 모드, 변경 승인 | 정확한 폴더와 허용 범위 확인 |
| 환경 점검 실패 | 로그인·파일 접근 실패인지, 구현 후 코드 오류인지 | 설치·권한 문제와 제품 결함을 분리; 코드 오류 때문에 전체 환경을 재설치하지 않음 |
| 다음 작업이 불명확 | 요구사항 승인·실제 결과·차단 기록 | 기존 문서와 코드를 근거로 현재 단계와 다음 작업 하나 요청; 단계 안내를 자동 실행으로 해석하지 않음 |
| 새 대화에서 이전 작업을 반복 | 인계 파일·현재 코드·재실행 기대 결과 | 인계 상태부터 확인하고 누락 정보를 질문; 이전 채팅을 전부 붙여넣지 않음 |
| 검토 과정에서 코드가 변경됨 | 검토 역할과 쓰기 범위 | 검토는 문제·재현 보고로 제한하고 수정은 구현 세션에 전달 |
| 프로그램 실행 실패 | 실행 위치·명령, 필요한 패키지, 오류 메시지 | 아래 형식으로 코딩 도우미에 수정 요청 |
| 결과가 기대와 다름 | 입력값·단위·누락 조건·계산 근거 | 정상 예시와 실제 결과를 나란히 설명 |
| Azure 구독이나 리소스가 안 보임 | 로그인 테넌트, 지정 구독, 접근 권한 | 고객 관리자 확인. 임의 다른 구독 사용 금지 |
| 모델·DB 연결 실패 | 대상 주소, 인증, 권한, 지역·할당량, 네트워크 정책 | 연결 하나씩 확인. 비밀 값 공유·방화벽 전체 개방 금지 |
| 저장·공유 실패 | 경로, 기존 파일, 사용자 권한 | 덮어쓰기·외부 공개 전에 대상과 내용을 확인 |

## 오류 보고 프롬프트

```text
현재 작업: [내용]. 실행 명령·행동: [내용]. 기대 결과: [내용]. 실제 결과: [내용]. 오류 메시지: [비밀 값 제거 후 입력]. 원인과 해결 순서를 설명하고 기존 정상 기능과 접근 권한 범위를 유지해줘. 수정 후 재확인 방법을 알려줘.
```

오류 메시지에서 비밀번호·API 키·토큰·개인정보를 제거합니다. 전체 인증 출력이나 설정 파일을 공개 GitHub 이슈에 올리지 않습니다.
