# 문제 해결

[처음으로](../README.md)

이 문서는 공통 진단 순서입니다. 명령은 환경·실행 가이드를 참고하세요. 실제 Azure 오류 화면은 리허설 후 추가합니다.

| 상황 | 먼저 확인할 것 | 하지 말아야 할 것 |
|---|---|---|
| 코딩 도구 로그인 실패 | 사용할 계정·사용 권한·조직 정책·네트워크 | 다른 사람의 계정·토큰 공유 |
| Azure 구독이 안 보임 | 로그인한 테넌트와 구독 접근 권한 | 임의의 다른 구독에 생성 |
| Foundry 생성 불가 | 생성 권한·정책·지원 지역 | 전체 구독 권한을 무조건 요청 |
| 모델 배포 불가 | 모델·지역·배포 유형·할당량 | 비용을 확인하지 않은 예약 용량 배포 |
| 모델 인증 오류 | Azure 로그인·테넌트·데이터 접근 역할 | API 키를 대화창에 붙여넣기 |
| 모델 사용량 제한 | 동시 호출·할당량·재시도 간격 | 무한 재시도 |
| 모델을 찾을 수 없음 | 배포 이름·OpenAI v1 엔드포인트 | 프로젝트 엔드포인트로 대체 |
| SQL 연결 시간 초과 | 서버 주소·승인된 네트워크 경로·방화벽 | 모든 IP 허용 |
| SQL 로그인 실패 | Entra 관리자·DB 사용자·인증 방식 | 관리자 비밀번호 배포 |
| SQL 테이블 접근 거부 | 선택 스키마와 조회 역할 | 에이전트에 DB 소유자 권한 부여 |
| 데이터가 없음 | 샘플 적재 여부·ID·조회 기간 | 모델이 데이터를 만들어 답하도록 변경 |
| Python import 오류 | 선택한 가상 환경·고정 의존성 | 전역 환경에서 무작위 업그레이드 |
| 계산 결과가 다름 | 중복 행·집계 범위·단위·0으로 나누기 | 모델에 숫자만 고치라고 요청 |
| 도구를 계속 반복 호출 | 호출 상한·도구 설명·인자·종료 조건 | 반복 상한 제거 |
| `NotImplementedError` | students의 선택한 calculate 함수가 미완성인지 | 설치 오류로 오해하고 패키지 재설치 |
| `SELECT-only access` | 참가자가 관리자·쓰기 권한 계정인지 | 코드의 권한 검사 삭제 |
| `FileExistsError` | 같은 이름의 출력 파일이 있는지 | 기존 파일 무단 덮어쓰기 |

## 도움 요청 형식

```text
선택한 시나리오:
진행 중인 단계:
실행한 명령 또는 입력한 요청:
기대한 결과:
실제 오류 메시지:
마지막으로 성공한 단계:
```

도움을 요청하기 전에 오류 메시지에서 비밀번호·키·토큰·개인정보를 제거합니다. 전체 설정 파일이나 인증 출력 전체를 공개 이슈에 올리지 않습니다.
