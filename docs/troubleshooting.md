# 진행이 막혔을 때

[워크숍으로 돌아가기](../README.md)

| 상황 | 확인할 것 | 대응 |
|---|---|---|
| 로그인·제작 기능이 안 됨 | 계정, 사용권, 조직 정책, 사용량 한도 | 지정 계정으로 확인하고 강사에게 문의 |
| CLI 명령을 찾지 못함 | 설치 완료, 새 터미널, 공식 지원 환경 | 설치 안내 확인. 무작위 패키지 추가 금지 |
| 파일이 바뀌지 않음 | 작업 폴더, Agent 모드, 변경 승인 | 정확한 폴더와 허용 범위 확인 |
| 프로그램 실행 실패 | 실행 위치·명령, 필요한 패키지, 오류 메시지 | 아래 형식으로 코딩 도우미에 수정 요청 |
| 결과가 기대와 다름 | 입력값·단위·누락 조건·계산 근거 | 정상 예시와 실제 결과를 나란히 설명 |
| Azure 구독이나 리소스가 안 보임 | 로그인 테넌트, 지정 구독, 접근 권한 | 고객 관리자 확인. 임의 다른 구독 사용 금지 |
| 모델·DB 연결 실패 | 대상 주소, 인증, 권한, 지역·할당량, 네트워크 정책 | 연결 하나씩 확인. 비밀 값 공유·방화벽 전체 개방 금지 |
| 저장·공유 실패 | 경로, 기존 파일, 사용자 권한 | 덮어쓰기·외부 공개 전에 대상과 내용을 확인 |

## 코딩 도우미에 전달할 내용

```text
현재 만들고 있는 것:
방금 한 행동 또는 실행 명령:
기대한 결과:
실제로 나온 결과:
오류 메시지:

원인과 해결 순서를 설명해줘.
기존 정상 기능과 접근 권한 범위는 유지해줘.
수정 후 내가 확인할 방법을 알려줘.
```

오류 메시지에서 비밀번호·API 키·토큰·개인정보를 제거합니다. 전체 인증 출력이나 설정 파일을 공개 GitHub 이슈에 올리지 않습니다.
