# 운영자 준비 사항

[처음으로](../README.md)

이 장은 참가자 필수 실습이 아닌 운영자 안내입니다.

## 구성 원칙

- 제공할 공통 환경은 강사가 지정한 코딩 도구의 사용 권한·작업 폴더·제작과 실행 안내입니다. Foundry·SQL·Python을 모두의 필수 환경으로 고정하지 않습니다.
- 실습 전에 [도구 비교 자료](tools-comparison.md)로 차이를 설명하고 당일 사용할 도구 하나를 지정합니다. 참가자가 각자 고르게 하지 않습니다.
- 아이디어 5개는 강사가 제시합니다. 참가자는 그중 하나를 선택하고 기능을 자유롭게 발전시킵니다. 앱·업무 도구·에이전트 등 결과물 형태를 고정하지 않습니다.
- 미완성 함수 채우기를 공통 과제로 지정하지 않습니다. 현재 코드의 학생용 함수와 완성본은 원하는 참가자를 위한 선택 예제입니다.
- 외부 모델·DB·호스팅은 기능 요구가 생겼을 때 결정합니다. 관리자 승인·비용·접속을 지원할 절차를 운영자가 준비합니다.
- 참가자가 배우는 내용과 무관한 패키지·방화벽 문제는 사전에 제거합니다.
- 자유 개선과 동료 논의 시간을 확보합니다. 투표·시상 규칙은 별도 결정입니다.

## 선택 예제 리허설 전에 확정

1. 새 리소스를 만들 Azure 구독과 승인된 비용 범위.
2. Foundry 모델·지역·배포 유형·동시 사용 할당량.
3. 개인별 또는 조별 실습 계정과 데이터 격리 방식.
4. 고객 PC의 Windows 네이티브 또는 WSL 실행 경로.
5. 선택한 코딩 도구 계정·정책과 모델 실행용 Azure 인증.
6. SQL 드라이버·Python·SDK 버전 및 정확한 설치 명령.
7. 행사 시간·인원과 사전 준비 일정.

## 실제 스크린샷 수집 순서

| 구간 | 캡처할 실제 화면 |
|---|---|
| Foundry | 새 프로젝트 진입, 설정, 생성 완료, 모델 배포, 첫 응답 |
| SQL | DB 생성 설정, 접속 설정, 합성 데이터 조회, 조회 권한 확인 |
| PC | 실습 폴더, 코딩 도구 실행, 인증 완료 여부, 모델·DB 연결 성공 |
| 각 시나리오 | 제작 요청, 변경 파일, 도구 호출, 결과물 |
| 개선 | 실패 또는 누락 사례, 수정 요청, 개선된 실제 실행 결과 |

실행하지 않은 결과를 모형 화면으로 대신하지 않습니다. 공개 자료의 이미지도 직접 실행한 화면처럼 사용하지 않습니다.

계정 이름·이메일·테넌트·구독 ID·인증 코드·키·토큰·개인정보가 없는 교육용 화면을 우선 사용합니다. 필요한 비식별 처리는 비공개 원본에서 수행한 뒤 **처리된 이미지만** 저장소에 추가합니다. 원본을 먼저 커밋하고 지우는 방식은 이력에 정보가 남습니다.

## 공통 안전 장치

- 읽기 전용 DB 역할과 명시적 테이블·뷰 접근.
- 인자 검증·매개변수화 쿼리·조회 결과 상한.
- 명시적 도구 허용 목록. 임의 SQL·셸 도구 금지.
- 파일 경로 정규화·outputs 외부 접근 차단·기존 파일 덮어쓰기 방지.
- 모델 출력 및 도구 루프 상한. 오류를 숨기지 않는 종료.
- 외부 발송·결제·예약·실제 업무 변경 도구 미제공.
- 실습 예산 알림과 사용량 관찰. 예산 알림은 자동 차단 장치가 아님.

프롬프트의 금지 문구만으로 이 조건을 구현했다고 간주하지 않습니다.

## 교재를 완료 상태로 바꾸기 전

참가자와 같은 권한으로 빈 환경에서 시작해 각 시나리오를 끝까지 실행합니다. 실제 생성 결과가 달라져도 복구용 완성 코드로 다음 단계에 합류할 수 있게 합니다. 정상 사례뿐 아니라 누락 값, 존재하지 않는 ID, 예산 불일치, 권한 없는 조회, 파일 경로 이탈도 확인합니다.

이번 공개 문서에는 내부 이메일·고객 비공개 일정·실제 계약·개인 계정·구독 정보가 들어가지 않습니다. 원격 게시 전에 게시할 파일과 내용을 검토합니다.
