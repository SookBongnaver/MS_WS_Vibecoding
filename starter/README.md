# 프로젝트 시작 템플릿

요구사항 정의·구현 계획·실행 검증·작업 재개에 사용하는 공통 문서와 AI 작업 지침입니다.

## 초기화 절차

1. 이 폴더를 VS Code에서 엽니다. (**File → Open Folder**)
2. 강사가 지정한 코딩 도구를 실행합니다.
3. 아래 내용을 대화창에 붙여넣고, 대괄호를 내 아이디어로 바꿉니다.

```text
AGENTS.md를 먼저 읽고 그 규칙대로 진행해줘. 나는 [사용할 사람]을 위한 [만들고 싶은 것]을 만들고 싶어. 사용자가 [입력할 내용]을 주면 [원하는 결과]가 나왔으면 좋겠어. 바로 코드를 만들지 말고 먼저 질문해줘.
```

## 작업 단계 및 역할

| 순서 | AI 수행 항목 | 참가자 수행 항목 |
|---|---|---|
| 1 | 부족한 정보를 하나씩 질문 | 대답하기 |
| 2 | `docs/1-무엇을만들까.md`와 세 가지 완료 조건 작성 | 입력·기대 결과 확인하기 |
| 3 | `docs/2-어떻게만들까.md` 작성 | 추가로 필요한 것 확인하기 |
| 4 | 코드 작성·직접 실행·결과 기록 | 같은 상황을 직접 사용해보기 |
| 5 | 수정·재확인·현재 상태 기록 | 불편한 점 말하기 |
| 6 | 새 검토 세션에서 완료 조건 재현·문제 보고 | 검토 결과 확인·수정 우선순위 결정 |

완료 조건은 **정상 입력·조건 변경·정보 누락** 세 가지입니다. 도구나 권한이 없어 실행하지 못한 사례는 성공이 아니라 **미실행**으로 남깁니다.

## 현재 단계 확인

```text
AGENTS.md와 docs 문서 2개, 현재 코드를 읽고 현재 단계·근거·차단 요인·다음 작업 하나·완료 판정 방법을 알려줘. 기록이 없는 승인이나 실행 결과를 추측하지 마. 아직 코드 수정이나 명령 실행은 하지 마.
```

별도 스킬 설치나 `/workflow` 명령은 필요하지 않습니다. 단계 안내는 문서·코드를 읽는 요청이며 자동 실행 기능이 아닙니다.

## 폴더 구성

```text
AGENTS.md    AI 작업 지침
docs/        요구사항 정의서·구현 계획서
.github/     GitHub Copilot 지침
```

만들어지는 파일은 이 폴더 안에 생깁니다.

## 새 대화에서 작업 재개

작업이 끝날 때 두 번째 문서에 현재 상태·관련 파일·남은 문제·재실행 명령과 기대 결과·다음 작업을 기록합니다. 동일 폴더에서 이전 대화를 넘기지 않는 새 대화를 열고 입력합니다.

```text
AGENTS.md와 docs 문서 2개, 현재 코드를 읽고 인계된 파일·상태를 확인해줘. 승인된 환경에서 재실행 명령의 결과가 기대와 일치하는지 확인해줘. 추가 비용·외부 연결이 필요하면 먼저 확인해줘. 불일치나 미실행 이유를 보고하고 다음 작업 하나를 제안해줘. 아직 코드는 바꾸지 마.
```

독립 검토를 수행하는 경우에는 새 세션에 해당 역할을 명시하고, 구현 코드·테스트를 변경하지 않은 채 두 번째 문서의 검토 결과만 갱신하도록 요청합니다.
