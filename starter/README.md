# 내 프로젝트

이 폴더에서 나만의 결과물을 만듭니다.

## 시작하기

1. 이 폴더를 VS Code에서 엽니다. (**File → Open Folder**)
2. 강사가 지정한 코딩 도구를 실행합니다.
3. 아래 내용을 대화창에 붙여넣고, 대괄호를 내 아이디어로 바꿉니다.

```text
AGENTS.md를 먼저 읽고 그 규칙대로 진행해줘.

나는 [사용할 사람]을 위한 [만들고 싶은 것]을 만들고 싶어.
사용자가 [입력할 내용]을 주면 [원하는 결과]가 나왔으면 좋겠어.

바로 코드를 만들지 말고 먼저 질문해줘.
```

## 다음에 일어나는 일

| 순서 | AI가 하는 일 | 내가 할 일 |
|---|---|---|
| 1 | 부족한 정보를 하나씩 질문 | 대답하기 |
| 2 | `docs/1-무엇을만들까.md` 작성 | 읽고 확인하기 |
| 3 | `docs/2-어떻게만들까.md` 작성 | 추가로 필요한 것 확인하기 |
| 4 | 코드 작성 | 직접 실행해보기 |
| 5 | 수정 | 불편한 점 말하기 |

## 폴더 안내

```text
AGENTS.md    AI가 따르는 규칙 (수정하지 않아도 됩니다)
docs/        AI가 채우는 문서 2개
.github/     Copilot용 규칙 (수정하지 않아도 됩니다)
```

만들어지는 파일은 이 폴더 안에 생깁니다.
