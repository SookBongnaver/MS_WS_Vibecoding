# 프로젝트 시작 템플릿

요구사항 정의·구현 계획·실행 검증·작업 재개에 사용하는 공통 문서와 AI 작업 지침입니다.

## 초기화 절차

1. 이 폴더를 VS Code에서 엽니다. (**File → Open Folder**)
2. 강사가 지정한 코딩 도구를 실행합니다.
3. 아래 내용을 대화창에 붙여넣고, 대괄호를 내 아이디어로 바꿉니다.

```text
AGENTS.md를 먼저 읽고 그 규칙대로 진행해줘. 나는 [사용할 사람]을 위한 [만들고 싶은 것]을 만들고 싶어. 사용자가 [입력할 내용]을 주면 [원하는 결과]가 나왔으면 좋겠어. 바로 코드를 만들지 말고 먼저 질문해줘.
```

## 작업 단계 및 역할

| 순서 | AI 수행 항목 | 참가자 수행 항목 |
|---|---|---|
| 1 | 부족한 정보를 하나씩 질문 | 대답하기 |
| 2 | `docs/1-무엇을만들까.md`와 세 가지 완료 조건 작성 | 입력·기대 결과 확인하기 |
| 3 | `docs/2-어떻게만들까.md` 작성 | 추가로 필요한 것 확인하기 |
| 4 | 코드 작성·직접 실행·결과 기록 | 같은 상황을 직접 사용해보기 |
| 5 | 수정·재확인·현재 상태 기록 | 불편한 점 말하기 |

완료 조건은 **정상 입력·조건 변경·정보 누락** 세 가지입니다. 도구나 권한이 없어 실행하지 못한 사례는 성공이 아니라 **미실행**으로 남깁니다.

## 폴더 구성

```text
AGENTS.md    AI 작업 지침
docs/        요구사항 정의서·구현 계획서
.github/     GitHub Copilot 지침
```

만들어지는 파일은 이 폴더 안에 생깁니다.

## 새 대화에서 작업 재개

작업이 끝날 때 AI가 두 번째 문서의 현재 상태·남은 문제·다음 작업을 갱신하도록 합니다. 같은 폴더에서 새 대화를 열고 입력합니다.

```text
AGENTS.md, docs/1-무엇을만들까.md, docs/2-어떻게만들까.md와 현재 코드를 읽어줘. 작동하는 것, 마지막 확인 결과, 남은 문제와 다음 작업 하나를 요약해줘. 기록이 없는 부분은 추측하지 마. 아직 코드는 바꾸지 마.
```
